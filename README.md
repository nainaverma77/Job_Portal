# Job Portal

A comprehensive MERN stack job portal application designed to connect job seekers with potential employers.

## Features
- User authentication (Job Seekers and Employers)
- Job posting and management
- Job search and filtering
- Application tracking

## Project Structure
- `frontend/`: React based user interface.
- `backend/`: Node.js/Express based API server.

## Getting Started

### Prerequisites
- Node.js
- MongoDB

### Setup
1. Clone the repository
2. Navigate to backend and run `npm install`, then start with `npm run dev` or `npm start`.
3. Navigate to frontend and run `npm install`, then start with `npm run dev`.
